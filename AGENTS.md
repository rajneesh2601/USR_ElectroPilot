## USR ElectroPilot 3D Dashboard

Before working on the 3D dashboard, always read:

- docs/3d-dashboard/GOAL.md
- docs/3d-dashboard/IMPLEMENTATION_PLAN.md
- docs/3d-dashboard/PROGRESS.md
- docs/3d-dashboard/VISUAL_ACCEPTANCE.md
- docs/3d-dashboard/PLC_MAPPING.md

Resume from the first incomplete phase in PROGRESS.md.

Do not mark a phase complete until its build and visual verification requirements pass.

Do not replace real PLC mappings with invented values.

Do not use the dashboard reference image as a static background.
